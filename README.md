# 대륙은 왜 움직일까 — 중2 수업용 시뮬레이션

중학교 2학년 「지권의 변화 · 대륙의 이동」 단원용 인터랙티브 자료입니다.
`index.html` 파일 하나만 있으면 됩니다. 인터넷 연결도, 설치도 필요 없습니다.

## 여는 법

`index.html` 을 더블클릭하면 브라우저에서 열립니다.
USB, 학교 LMS, 구글 클래스룸 어디에 올려도 그대로 동작합니다.
크롬·엣지·사파리, PC·태블릿 모두 지원하며 터치로도 조작됩니다.

## 두 개의 탭

**① 해안선을 맞춰보자** — 대륙 조각을 직접 끌어다 붙여보는 퍼즐입니다. 5단계입니다.

| 단계 | 대륙 | 기준(고정) | 여기서 보여줄 것 |
|---|---|---|---|
| ① 남미·아프리카 | 2개 | 아프리카 | 가장 유명하고 가장 잘 맞는 정합. 도입용 |
| ② 호주·남극 | 2개 | 남극 | 대서양만 그런 게 아니다. 우연의 반복이 아님 |
| ③ 곤드와나 | 3개 | 아프리카 | 아프리카·인도·남극. 화석 띠가 세 대륙을 가로지름 |
| ④ 로라시아 | 3개 | 아프리카 | 북대서양. 고위도라 덜 맞는 이유를 함께 다룸 |
| ⑤ 판게아 전체 | 7개 | 아프리카 | 종합 |

- 단계마다 화면이 그 대륙들에 맞게 **자동으로 확대**됩니다.
- 조각을 누르면 위에 **회전 손잡이**가 생깁니다. 손잡이를 끌거나 `↺ ↻` 버튼으로 돌립니다.
- 위치와 각도가 어느 정도 맞으면 **저절로 달라붙습니다**. 정확히 맞출 필요는 없습니다.
- **자동 재생**: 판게아에서 현재까지 2억 5천만 년을 슬라이더로 재생합니다. 교사 시연용.
- **증거 겹쳐보기**: 화석 분포 · 빙하 흔적 · 대륙붕을 켜고 끌 수 있습니다.
  화석은 점이 아니라 **띠**로 그려집니다. 대륙을 맞추면 끊겨 있던 띠가 이음매에서
  다시 이어집니다. 넷이 한꺼번에 나오면 남부 아프리카에서 뒤엉키니,
  **범례의 화석 이름을 눌러 하나씩** 보세요. 수업 발문에도 그 편이 낫습니다.

**② 판은 어떻게 생기고 사라질까** — 맨틀 대류 단면 애니메이션입니다.
해령에서 새 해양 지각이 만들어져 양옆으로 밀려나고, 해구에서 섭입해 사라집니다.
해양 지각의 **색이 나이**입니다. 해령에서 멀수록 오래되었다는 것이 해저 확장의 증거입니다.

## 45분 수업 흐름 (예시)

| 시간 | 활동 | 발문 |
|---|---|---|
| 5분 | **도입** — ① 탭 ①단계를 띄운다 | "세계 지도를 보다가 이상한 점 느껴본 사람?" |
| 8분 | **탐구 1** — 학생이 남아메리카를 직접 맞춰본다 | "정말 맞을까? 직접 해보고 얘기하자" |
| 5분 | **반증 흔들기** — ②단계 호주·남극 | "우연히 닮은 걸 수도 있잖아요? 그럼 다른 대륙도 해볼까" |
| 8분 | **탐구 2** — ③단계 곤드와나 + 화석 토글 | "메소사우루스는 민물에 살았어요. 바다를 헤엄쳐 건넜을까요?" |
| 7분 | **종합** — ⑤단계 판게아 전체 (모둠) | "먼저 어느 대륙부터 놓는 게 쉬울까?" |
| 7분 | **전환** — ② 탭 | "그런데 대륙이 **왜** 움직이지? 무엇이 밀고 있을까?" |
| 5분 | **정리** — ① 탭 자동 재생으로 마무리 | "대륙이동설은 '움직였다', 판 구조론은 '왜 움직이는지'예요" |

시간이 부족하면 ②·④단계를 건너뛰고 ① → ③ → ⑤로 가면 됩니다.
④단계(로라시아)는 "왜 여기는 덜 맞지?"를 다룰 여유가 있을 때만 쓰세요.

## 수업 전에 알아두면 좋은 것

**용어**: 해안선 일치는 베게너의 **대륙이동설** 증거입니다. **판 구조론**은 그 이동의
원인을 설명하는 후속 이론입니다. ①번 탭이 대륙이동설, ②번 탭이 판 구조론에 해당합니다.

**자주 나오는 오개념**

- *"해안선이 딱 맞아야 하는 것 아닌가요?"* → 진짜 대륙의 경계는 물에 잠긴 **대륙붕**
  가장자리입니다. `대륙붕` 토글을 켜면 왜 조금 겹치거나 벌어지는지 보여줄 수 있습니다.
- *"대륙이 바다 위를 떠다니나요?"* → 대륙만 따로 움직이는 게 아니라, 대륙을 실은 **판**
  전체가 움직입니다. ②번 탭이 이 지점을 다룹니다.
- *"지구가 점점 커지나요?"* → 해령에서 만들어지는 만큼 해구에서 사라집니다.
  ②번 탭에서 해저를 덮은 조각 수가 늘지도 줄지도 않는 것을 보여주세요.
- *"남극이 왜 저렇게 생겼어요?"* → 남극만 다른 지도 도법(남극점 중심)으로 그렸습니다.
  교과서 세계지도에서는 아래로 길게 늘어나 보이지만 실제로는 둥근 대륙입니다.
- *"④단계는 왜 잘 안 맞아요?"* → 정거원통도법은 고위도로 갈수록 동서로 늘어납니다.
  그린란드와 유럽이 둘 다 부풀어 겹쳐 보이는 것이지, 실제로 안 맞는 것이 아닙니다.
  ①·②단계가 잘 맞는 이유도 같습니다 — 적도 부근이라 왜곡이 작습니다.

## 자료의 한계 (학생에게 안내할 것)

- 판게아에서 현재까지의 **이동 경로는 단순 보간**입니다. 시작과 끝은 실제에 가깝지만
  중간 시점의 위치는 실제 고지리 복원과 다릅니다.
- 대륙 모양은 정거원통도법(교과서 세계지도와 같은 도법)이라 고위도가 동서로 늘어나 있습니다.
  그래서 북아메리카·유라시아의 맞물림은 남아메리카–아프리카만큼 정확하지 않습니다.
- ②번 탭 단면도는 세로로 크게 과장되어 있습니다. 실제 판은 1년에 몇 cm씩 움직입니다.
- 빙하 흔적은 개념 전달용 근사 도형입니다.
- 화석 띠는 실제 산지를 하나하나 옮긴 것이 아니라, 각 대륙에서 그 화석이 나오는
  지역을 지나가도록 잡은 개략 경로입니다. 판게아로 모으면 띠가 대륙 경계를 넘어
  이어진다는 것을 보이는 것이 목적입니다.

## 개발자용

| 파일 | 역할 |
|---|---|
| `index.html` | **원본.** 시뮬레이션 전체. 라이브러리·빌드 없음 |
| `pangaea.html` | 웹 링크(Artifact) 발행용 사본. `index.html` 에서 자동 생성 |
| `build_shapes.py` | Natural Earth 110m → 대륙 조각 SVG path 생성 (`> shapes.js`) |
| `fit_pangaea.py` | 판게아 목표 위치 계산 → `index.html` 의 TARGET 교체 |
| `shapes.js` | 생성된 좌표. `fit_pangaea.py` 가 읽는다 |

`fit_pangaea.py` 는 두 단계로 맞춥니다. 판게아 복원도를 보고 잡은 출발 배치에서
시작해, 이미 배치된 대륙들의 해안선으로 부호 있는 거리장을 만들고 "겹치지 않으면서
가장 촘촘히 붙는" 위치를 그 주변 좁은 범위에서만 찾습니다. 탐색을 넓게 열면 촘촘함만
좇다가 대륙이 아무 해안 홈에나 끼워져 지질학적으로 엉뚱한 판게아가 나옵니다.

화석 띠도 같은 스크립트가 만듭니다. 띠를 판게아 위에 하나로 그린 뒤 대륙별로 잘라
각 조각의 로컬 좌표로 저장하므로, 학생이 판게아를 맞추면 잘렸던 띠가 정확히 다시
이어집니다. 대륙을 건너가는 구간은 두 대륙이 실제로 맞닿는 지점을 자동으로 찾아
그리로 지나가게 합니다 — 손으로 좌표를 맞추면 이음매에서 띠가 벌어집니다.

대륙 모양이나 판게아 배치를 다시 뽑을 때:

```bash
python3 build_shapes.py > shapes.js && python3 fit_pangaea.py
```

`index.html` 을 고친 뒤 웹 링크용 사본을 다시 만들 때
(Artifact 는 `<html>`/`<head>`/`<body>` 껍데기를 스스로 감싸므로 벗겨서 넘긴다):

```bash
python3 -c "import re;s=open('index.html').read();s=re.sub(r'^.*?<meta name=\"viewport\"[^>]*>\n','',s,flags=re.S).replace('</head>\n<body>\n','').replace('\n</body>\n</html>\n','\n');open('pangaea.html','w').write(s)"
```

동작 점검: `index.html?selftest=1` 로 열면 각도 계산·스냅 판정·데이터 무결성을 확인합니다.
목표 위치를 다시 잡고 싶으면 `index.html?tune=1` 로 열어 자유롭게 배치한 뒤 `D` 키를
누르면 콘솔에 좌표가 찍힙니다.

대륙 외곽선 출처: [Natural Earth](https://www.naturalearthdata.com/) (퍼블릭 도메인).
